Privacy policy

Mixilith Studio is a private livestream and editing workspace operated by Michael Njuki. This notice describes the data used to operate the workspace and its connected services.

YouTube API Services

Studio uses YouTube API Services. Google handles sign-in and its own processing under the Google Privacy Policy. Studio never asks for a Google password. Its server stores OAuth tokens locally to keep the connected YouTube channel signed in.

Studio uses channel details, subscribers, video and playlist metadata, public search results, and viewer counts to show the channel, recent uploads and research results. It uses broadcast IDs, stream status, ingest keys, live chat messages, and the senders' public channel identifiers and display names to configure and monitor streams, show chat, and support moderation. Studio uses the connected channel's permission to start and end broadcasts and apply the operator's chosen titles, descriptions and thumbnails.

Recording, storage and services

OBS recordings, local transcripts and clip drafts are stored on the operator's Mac. The local database stores broadcast reports, API caches, chat history, research collections and account connection state. When streaming through the configured Azure relay, the relay receives the OBS stream and forwards it to the destinations the operator enabled. YouTube and Twitch process chat and moderation actions sent to their services. The embedded YouTube player and remote thumbnails load from YouTube and can process device, network and usage information. Studio stores workspace preferences in the browser.

OpenAI receives inputs for cloud features. Inputs can include the selected transcript, chat excerpts used by Ask AI, public research examples and video metadata when drafting titles or descriptions. Research alerts can request briefs in the background if enabled. Google OAuth tokens and stream keys stay outside model prompts. Local model requests are processed on the Mac.

Disconnecting and deleting data

In Settings → Connections, choose Disconnect YouTube and clear data. Google also lets you revoke access in Google Account connections. Studio deletes the local connection, saved YouTube stream keys, chat and viewer history, upload and research caches, and links between Studio plans and YouTube videos. It keeps OBS recordings, local transcripts, notes, and editing drafts. Studio also asks Google to revoke access. If Google is unreachable, you can revoke access using the account link above. Use YouTube Studio to manage videos and messages on YouTube.

For a copy or deletion of locally stored personal data, or to ask a privacy question, contact mikenjuki@gmail.com. Studio clears or refreshes cached YouTube data within 30 days. It checks Google authorization while it is running and clears local YouTube data when Google reports that authorization has expired or was revoked.
